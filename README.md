# zapretgui

Приложение для Windows 10/11 x64 для управления zapret и TG WS Proxy. Панель запускает утилиты, проверяет стратегии и задержку для YouTube, Discord и Telegram, позволяет редактировать списки обхода и исключений, Game Filter и IPSet.

**Установка:** скачай [установщик](release/zapretgui_Setup_x64.exe), запусти его и нажми **Скачать обе утилиты** во вкладке **Установка и тесты**.

**Обновления:** zapret и TG WS Proxy скачиваются из официальных репозиториев Flowseal. Сама панель обновляется из этого репозитория через **Настройки → Обновить**.

**Сборка:** `makensis FlowPanel/Installer.nsi`. При публикации меняй установщик в `release/`, номер версии и SHA-256 в `release/update.json` одним коммитом.
