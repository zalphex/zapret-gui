# zapretgui 2.0.0

Панель на C# для zapret и TG WS Proxy от Flowseal. Windows 10 или 11 x64 на Intel/AMD, .NET Framework 4.8 или 4.8.1.

## Установка

1. Если запущена предыдущая версия zapretgui, нажми правой кнопкой на её значок в трее и выбери «Выход».
2. Запусти `zapretgui-2.0.0-setup-x64.exe`, выбери папку и открой приложение. Установщик поддерживает обновление поверх прежней версии.
3. При первой установке открой «Установка и тесты» и нажми «Скачать обе утилиты». Затем нажми «Автовыбор и запуск» для нужного компонента или выбери конфиг и нажми «Применить». Подключение прокси в Telegram Desktop подтверждается при первом переходе по кнопке «Подключить Telegram».

## Вкладки

- **Статус** показывает запущенные компоненты, профиль, версию и журнал. «Обновить статус» параллельно проверяет YouTube, Discord и Telegram. Для Telegram проверяются веб-доступ и ICMP. При работающем локальном прокси панель дополнительно отправляет запрос MTProto к дата-центру Telegram. В карточке видно, какой транспорт ответил. Доступность веб-страницы и голосового соединения Discord может различаться.
- **Установка и тесты** скачивает и обновляет утилиты из официальных релизов Flowseal. Можно открыть папку конфигов, применить стратегию, остановить или перезапустить компонент. Проверка временно переключает профили и делает по две попытки для каждой из двух целей. Сначала учитывается число доступных целей, затем число успешных ответов, затем среднее время. «Проверить конфиги» возвращает исходное состояние и выделяет победителя. «Автовыбор и запуск» временно включает лучшую стратегию zapret. Проверь видео YouTube и голос Discord в своих клиентах и нажми «Сохранить конфиг». При отказе или по истечении двух минут панель возвращает прежнее состояние. Для профилей TG WS Proxy по-прежнему используются замеры MTProto. Проверку можно отменить. Здесь же есть раздельный пинг трёх сервисов и обслуживание службы zapret.
- **Настройка обхода** управляет игровым фильтром TCP/UDP, диапазонами портов, IPSet и шаблонами пакетов. В редакторе есть четыре файла из таблицы ниже. Если файл уже изменён другим редактором, панель предложит перечитать его. При обновлении IPSet предыдущая версия сохраняется в папке списков. В режимах «Выключен» и «Все IP» редактируется резервный список для режима «По списку».
- **Настройки** управляют автозапуском, фоновым входом в Windows, сворачиванием в трей, настройками прокси и обновлением самой панели. Автозапуск включается отдельно. Запускать в фоне и сворачивать в трей включены по умолчанию для новых установок. При запуске панели установленные компоненты стартуют с сохранёнными настройками.

| Файл | Содержимое |
| --- | --- |
| list-general-user.txt | Домены для обхода, включая их поддомены |
| list-exclude-user.txt | Домены-исключения, в том числе для сетей из IPSet |
| ipset-all.txt | IP-адреса и подсети |
| ipset-exclude-user.txt | IP-адреса и подсети, которые нужно исключить |

Файлы с окончанием `-user.txt` создаются при установке или первом запуске zapret. В штатной поставке Flowseal это также делает `service.bat`.

## Окно, трей и обслуживание

В окне и трее используется значок zapretgui. Двойной щелчок по нему открывает окно. Правая кнопка даёт доступ к ссылке Telegram, настройкам, журналу, перезапуску и остановке прокси. Панель скрывает значок управляемого TG WS Proxy после его появления в трее. Несохранённые изменения в списке или фильтрах остаются в памяти при сворачивании. Обычный выход из панели оставляет запущенные сетевые компоненты работать.

В выбранной папке установки находится подпапка `zapretgui.runtime`. В ней лежат панель, конфиги и списки (`Zapret`), прокси с настройками (`TG`) и `state.json`. В новой папке компоненты скачиваются заново. Для стратегий читается команда запуска `winws.exe` из BAT-файла Flowseal. Файлы с произвольной командной логикой потребуют адаптации. Сама панель запускает компоненты напрямую. Для службы и параметров TCP используются штатные средства Windows.

В «Обслуживании» доступны установка и удаление службы zapret, диагностический журнал, обновление hosts, настройка TCP timestamps и очистка кэша Discord. Перед применением hosts есть предпросмотр и резервная копия. «Восстановить hosts» удаляет блок, добавленный панелью, с сохранением остальных записей. Конфликтующую службу можно остановить и снова запустить. WinDivert виден в диагностике.

## Обновление панели

«Обновить zapretgui» читает опубликованный манифест из `zalphex/zapret-gui`. Более новая версия скачивается, сверяется по SHA-256 и метаданным установщика, затем устанавливается. Установщик Windows x64 доступен в разделе [Releases](https://github.com/zalphex/zapret-gui/releases/latest).

## Исходный код

Для сборки в Windows открой Developer Command Prompt для Visual Studio с MSBuild, .NET Framework 4.8 Developer Pack и NSIS 3. Запусти `build.cmd` в папке исходников. Результат появится в `bin`. Папка Tests содержит автономные проверки. CoreChecks.exe также принимает путь к папке стратегий Flowseal для проверки их разбора.

Интерфейс WPF, управление сеансом, тестирование и обработка конфигов написаны для версии 2.0. Из ветки 1.x сохранены значок, низкоуровневая реализация MTProto, привязка значка Windows и совместимость с прежним установщиком.
