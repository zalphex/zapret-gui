zapretgui · Windows 10/11 x64 (Intel / AMD)

Запуск
1. Запусти zapret_GUI_Setup_x64.exe и выбери папку приложения.
2. Открой zapretgui через меню «Пуск» или с последней страницы установщика.
3. Во вкладке «Установка и тесты» нажми «Скачать обе утилиты».
4. Для zapret и TG WS Proxy можно запустить «Автовыбор и запуск» или вручную
   выбрать нужный конфиг и нажать «Применить».
5. Для Telegram Desktop после запуска прокси нажми «Подключить Telegram»
   и подтверди добавление прокси в самом Telegram.

Проверки
• Вкладка «Статус» показывает состояние процессов и результаты сетевых замеров.
  «Обновить статус» проверяет YouTube, Discord и Telegram.
• «Пинг сервисов» показывает ICMP и время ответа HTTPS. Для Telegram при
  работающем прокси дополнительно измеряется ответ MTProto через прокси.
• Для zapret идут два HTTPS-замера на YouTube и два на API Discord.
  Эти запросы проверяют доступность указанных адресов. Видео и голосовой
  канал проверяются в соответствующих клиентах.
• Для TG WS Proxy идут по два MTProto-запроса к дата-центрам DC2 и DC4.
  Три профиля отличаются настройками CF и HTTP/2.
• Побеждает конфиг с ответами от наибольшего числа целей, затем с наибольшим
  числом ответов и наименьшей средней задержкой. Если ответов нет, предыдущий
  конфиг сохраняется. Сам тест временно перезапускает проверяемую утилиту.
• Кнопка «Проверить конфиги» возвращает предыдущий конфиг после замеров и
  выбирает победителя в списке. «Автовыбор и запуск» сразу применяет его.

Установка и процессы
Утилиты скачиваются с официальных GitHub-репозиториев Flowseal. Обновление
заменяет файлы в папке приложения, сохраняя конфиг TG WS Proxy и пользовательские
списки zapret. Папка утилит и настроек — %ProgramFiles%\zapretgui.
zapretgui запоминает выбранные конфиги. Работающие процессы остаются после
закрытия панели. При открытии панели установленные утилиты запускаются
автоматически с сохранёнными настройками. При первом запуске zapret без
сохранённой стратегии панель применяет general.bat.
Если уже запущен отдельный zapret или TG WS Proxy, сначала останови его.
Служба zapret останавливается в services.msc. Для сетевого теста Telegram
локальный прокси должен слушать 127.0.0.1, по умолчанию порт 1443.

Настройки
• «Автозапуск zapretgui» открывает панель при входе в Windows текущего
  пользователя. Для запуска используется копия в %ProgramFiles%\zapretgui\Desktop.
  Чтобы убрать задачу автозапуска, выключи этот переключатель.
• «Убирать окно в трей» включено по умолчанию. Кнопки «Свернуть» и «×» скрывают окно.
  Двойной щелчок по значку в трее возвращает окно, а пункт «Выход»
  в меню значка закрывает панель.
• «Папка» рядом с тестами открывает папку стратегий zapret или config.json прокси.
  Если меняешь файлы в Program Files, подтверди запрос Windows. После изменения
  обнови статус, чтобы перечитать список стратегий, и перезапусти утилиту.
• Game Filter поддерживает выключенный режим, TCP, UDP и TCP + UDP.
  IPSet поддерживает режимы по списку, выключен и все IP.
  «Применить фильтры» перезапускает работающий zapret.

• «Обновить IPSet» скачивает список Flowseal и сохраняет предыдущий список
  рядом в файле ipset-all.txt.before-update.*.bak. В режимах «Выключен» и
  «Все IP» свежий список активируется при переключении на «По списку».
• «Папка списков» ведёт к спискам адресов и исключений. Файлы *-user.txt
  создаются при первом запуске zapret или service.bat.
• «Настройка обхода» содержит Game Filter, IPSet и редактор четырёх списков.
  Выбери файл, нажми «Загрузить список», внеси изменения и сохрани.
  Сохранение активного списка перезапускает zapret, если он запущен.
• При обновлении со старой версии списки и настройки копируются из
  %ProgramFiles%\FlowPanel. Исходные файлы остаются там как резервная копия.

Обновление приложения
• «Настройки» → «Обновить» проверяет версию установщика в zalphex/zapret-gui.
  Если версия новее, программа скачает её, закроется, установит обновление
  и откроется снова. Для приватного репозитория один раз сохрани токен GitHub
  с правом Contents: Read-only.
